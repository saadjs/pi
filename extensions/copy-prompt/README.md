# @saadjs/pi-copy-prompt

A tiny pi extension that copies the current unsent prompt to the system clipboard.

## Install

```bash
pi install npm:@saadjs/pi-copy-prompt
```

## Usage

Press `Ctrl+Shift+C` while the pi editor is focused. The editor contents remain unchanged.

Pi uses its system clipboard support, including the macOS clipboard when running locally on a Mac.
