# @saadjs/pi-git-status

## 0.2.0

### Minor Changes

- Show the current branch's GitHub PR as a clickable `#N` link, colored by state (open, draft, merged, closed). It's looked up with `gh` and refreshed on branch changes, after push and `gh pr` commands, and on an idle-aware poll. Hidden when `gh` is missing or signed out.
